# AZ-104 Study Labs

Goal: Prepare for the Microsoft AZ-104 Azure Administrator exam in 4–6 weeks.

## Study Areas
- Identity and governance
- Storage
- Compute
- Networking
- Monitoring and backup

## Weekly Plan
- Week 1: Azure foundation, identity, governance
- Week 2: Storage
- Week 3: Compute
- Week 4: Networking
- Week 5: Monitoring, backup, review
- Week 6: Practice exams and final labs

## Daily Workflow
1. Complete the assigned lab
2. Save notes
3. Save screenshots
4. Write what I learned
5. Review weak areas
